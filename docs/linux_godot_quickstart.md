# Linux / Godot 4 Quick Start

1. Godot 4'ü kurun.
2. Bu klasörü açın.
3. `project.godot` dosyasını çalıştırın.
4. `scenes/Main.tscn` sahnesini açın.
5. `assets/production` içindeki modelleri import edin.
6. `scripts/Soldier.gd` ve `scripts/Main.gd` üzerinde karakter/animasyon bağlamalarını yapın.
7. `ui` klasöründen HUD ikonlarını bağlayın.
8. Export işlemi için `Project > Export` menüsünü kullanın.

Linux önerileri:
- Godot 4 tarayıcıdan doğrudan çalıştırılsa da, dizin izinlerine dikkat edin.
- `chmod +x` gerektiğinde terminalden izin verin.
- Oyun buildi sırasında `--headless` veya uygun export profile kullanın.
