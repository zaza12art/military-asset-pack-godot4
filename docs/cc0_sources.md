# CC0 / Ücretsiz Kaynak Önerileri ve Politikalar

Orijinal, gerçekçi modeller ve ses kaydetmek zaman alır. Aşağıdaki ücretsiz/CC0 kaynakları kullanarak hızlıca üretime geçebilirsiniz. Her dosya eklemeden önce kaynağın lisansını kontrol edin.

Önerilen kaynak türleri:
- 3D modeller: Sketchfab (CC0/allow downloads), Poly Haven, Khronos Sample Models (glTF örnekleri)
- Textures & PBR: Poly Haven textures, AmbientCG (CC0)
- Ses: Freesound.org (CC0/CC BY variant), OpenGameArt (CC0/CC BY)
- UI ikonlar: FontAwesome (SIL/Free), custom SVG tasarım

Lisans uyarısı:
- "CC0" en serbestidir; atıf gerektirmez.
- CC BY / CC BY-SA kullanacaksanız, README içinde attribution listesi ekleyin.
- Ticari kullanım planlıyorsanız (store release vb.) 3. parti modellerin lisanslarını dikkatle inceleyin.
