# Usage

1. Godot 4 kurun.
2. Bu klasörü import edin.
3. `project.godot` dosyasını açın.
4. `scenes/Main.tscn` içinden sahneyi çalıştırın.
5. Linux üzerinde çalıştırmak için Godot binary dosyasını çalıştırın.

Not:
- Bu proje, örnek sahne ve katalog düzeni içerir.
- Asıl üretim dosyaları için lisanslı/CC0 kaynaklar eklenmelidir.
