# Asset folders

Bu klasörler, oyun için gerekli alanları organize etmek amacıyla hazırlandı.

- `characters/` : Asker varyantları
- `weapons/` : Tüfek, tabanca, bomba, roketatar, granat
- `animations/` : Idle, Walk, Run, Reload, Fire, Death vb.
- `sounds/` : Atış, patlama, ses efektleri ve ambient
- `ui/` : HUD ikonları, menü, hedef işaretleri
- `materials/` : PBR malzemeler

Geliştirme notu:
- Bu klasörler hazır bir plan sunar.
- Gerçek üretim çözümlerinde burada lisanslı veya CC0 kaynak dosyaları saklanır.
