# Characters

Bu klasöre aşağıdaki 8 asker varyantı için üretim dosyaları eklenir:

1. Rifleman
2. Medic
3. Support
4. Sniper
5. Heavy
6. Engineer
7. Recon
8. Commander

Beklenen dosya türleri:
- .blend / .fbx / .glb / .gltf
- albedo, normal, roughness, metallic textures
- rig file
- idle, walk, run, reload, fire, death animasyonları

Bu sürüm yalnızca katalog ve plan amaçlıdır.
